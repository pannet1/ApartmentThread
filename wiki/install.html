Installation Overview & Sequence

Five sequential stages, aligned strictly with the real physical build path. The server and Thread radio mesh are stood up and proven on the bench first, creating the local infrastructure needed to pair Matter-over-Thread sensors before any mains switch plate is disturbed.

Why this sequence is non-negotiable

You cannot commission a Matter-over-Thread sensor without a running Home Assistant instance and an active Thread mesh. Similarly, smart switch plates must be proven in software with offline manual override before cutting wall wires. The sequence itself is the safety mechanism.

The Five Pass/Fail Gate Rules

  1. One gate per stage: A test failure in any stage halts progress immediately. Never move to the next stage hoping to debug an earlier component simultaneously.
  2. Offline-first verification: Every stage must pass its local survivability test with the router's WAN/internet cable disconnected.
  3. Manual override sanctity: If Home Assistant is stopped, every physical wall rocker switch must continue to turn its light or fan on and off mechanically.
  4. Cheapest failure first: Software flashing and bench integration happen before cutting wires or drilling holes.
  5. Configuration backups: Every successful stage ends with an off-device backup of configuration files and datasets.
