Stage 3b — Door Contact Sensor Bench Build (DS-1)

Bench-assembling, wiring, flashing, and testing the ultra-low-latency Matter-over-Thread door contact sensor. Joins the same IEEE 802.15.4 Thread mesh established in Stage 2 to deliver instantaneous lighting triggers before stepping across the bathroom threshold.

Stage 3b Objective

Build and verify the DS-1 Door Contact Sensor. In Indian apartments where the bathroom switchboard is directly adjacent to the door frame, the default approach is the Hardwired Dummy Channel: an MC-38 reed switch (₹57 on Robocraze / Amazon India) connected into switch input S2 of the in-wall Tinxy module running on-chip ESPHome logic (O-12, O-13). For distant switchboards without conduit, the alternative battery-powered Matter over Thread (XIAO ESP32-C6) build is also provided.

1. Sensor Architecture: Hardwired Dummy Channel vs Wireless

Because the bathroom door serves as an absolute physical boundary, detecting door transitions enables instant lighting and continuous occupancy locking:

  • Track A (Default — Hardwired Dummy Channel): Senses door state via a dry contact MC-38 reed switch wired straight into the bathroom switchboard's S2 input. The onboard ESP8266 runs custom ESPHome firmware, evaluating the occupancy state machine directly on silicon (<5ms latency). It operates 100% standalone with zero hub/server dependency, and requires zero batteries forever.
  • Track B (Wireless — Matter over Thread): Uses a Seeed Studio XIAO ESP32-C6 running as a Thread Sleepy End Device (<5μA deep sleep, 4–5 year LiPo life) joining the central M5Stack ESP32-H2 border router mesh when running conduit to the switchboard is impractical.

2. Direct Interconnect & Wiring Schemes (O-13)

Select the wiring scheme matching your bathroom layout:

Track A: Hardwired Dummy Channel Wiring (Tinxy In-Wall Module)

Switchboard Dummy Channel Connections
  • Mounting: Mount the passive MC-38 reed switch capsule on the exterior door frame header or strike jamb; mount the magnet on the moving door leaf (≤15mm gap).
  • Cable Pull: Pull a thin, mains-rated 2-core insulated cable (0.5–0.75 mm², 1,100V grade) through concealed casing or conduit into the adjacent bathroom switchboard box.
  • Tinxy Module Wiring:
    • Phase (P) & Neutral (N): Connected to 230V AC mains.
    • L1 (Load 1): Connected to the bathroom light (and exhaust fan in parallel).
    • S1 (Switch 1): Connected to the manual wall rocker switch on the faceplate.
    • L2 (Load 2): Left completely unconnected (the Dummy Channel).
    • S2 (Switch 2): The two wires from the door's MC-38 reed switch connect across S2 and Phase (or the module's switch common terminal).
  • Safety Isolation: Ensure all connections inside the switchboard use heat-shrink or screw terminals to maintain total isolation from exposed metal frames.

Track B: Battery-Powered Matter-over-Thread Wiring (XIAO ESP32-C6)

3. Flashing Matter-over-Thread Firmware

The Seeed Studio XIAO ESP32-C6 runs open-source Matter-over-Thread Contact Sensor firmware based on Espressif ESP-Matter and the ESP-IDF framework.

A. Toolchain Setup & Repository Clone

# 1. Install prerequisites
sudo apt-get update && sudo apt-get install -y git python3-pip cmake ninja-build

# 2. Clone ESP-Matter with submodules
mkdir -p ~/esp && cd ~/esp
git clone --depth 1 --recursive https://github.com/espressif/esp-matter.git
cd esp-matter
./install.sh

B. Build & Flash via USB-C

Connect the XIAO ESP32-C6 to your PC via USB-C, identify its port (typically /dev/ttyACM0 or /dev/ttyUSB0), and compile the contact sensor example targeting Thread:

cd ~/esp/esp-matter/examples/contact_sensor
source ~/esp/esp-matter/export.sh

# Configure target for ESP32-C6 and Thread
idf.py set-target esp32c6

# Build and flash
idf.py -p /dev/ttyACM0 build flash monitor
Pre-Built Binary Option Available

If you prefer not to compile ESP-IDF from source on your workstation, you can flash the pre-compiled binary directly using esptool.py:

pip install --user esptool
esptool.py -p /dev/ttyACM0 -b 460800 --chip esp32c6 write_flash 0x0 ds1_matter_thread.bin

C. Extract Onboarding Codes

During the first boot in the monitor terminal, the firmware outputs the standard Matter pairing discriminator, QR code URL, and manual pairing code:

I (892) chip[DL]: Setup Discriminator: 3840 (0xf00)
I (895) chip[DL]: Setup Passcode: 20202021
I (901) chip[SVR]: Manual pairing code: [34970112332]
I (908) chip[SVR]: Setup QRCode: [MT:Y.K90-Q000KA0648G00]

4. Commissioning into Home Assistant

Commissioning the door sensor follows the same local-first flow as the presence sensor:

  1. Keep Sensor in Direct Line-of-Sight: For initial Thread pairing, place the XIAO ESP32-C6 within 1–2 meters of the Radxa server / ESP32-H2 border router.
  2. Open Home Assistant Companion App: Ensure your phone is connected to the local home Wi-Fi network.
  3. Add Matter Device: In Home Assistant, go to Settings → Devices & Services → Add Integration → Add Matter Device.
  4. Scan QR or Enter Code: Enter the manual pairing code from the firmware build (e.g. 34970112332).
  5. Assign Area: Name the entity `Bathroom Door Sensor` and assign it to the Bathroom area.
  6. Verify State: Home Assistant will create binary_sensor.bathroom_door under the Matter integration.

5. Bench Testing & Latency Verification

Before final adhesive mounting on the door frame, run this 3-step bench test to prove latency and contact behavior:

Bench Test Sequence
  1. Closed State Test (Magnet In Contact): Hold the magnet piece directly against the MC-38 sensor body (gap <10 mm). Confirm that binary_sensor.bathroom_door in Home Assistant shows `Off` (Closed).
  2. Open State Test (Magnet Removed): Pull the magnet away (>20 mm). Confirm that the state flips immediately to `On` (Open) in under 50 ms. closes O-12
  3. Rapid Toggle Stress Test: Move the magnet back and forth rapidly 5 times. Confirm that Home Assistant records every single transition without dropping packets or stalling the Thread border router.

6. Physical Enclosure & Door Frame Mounting

Once bench testing passes, mount the door sensor on the bathroom door following these architectural guidelines:

  • Exterior Frame Location: Mount the sensor body (with XIAO and battery) on the outside header jamb or exterior door frame. This keeps the electronics 100% protected from shower steam and condensation.
  • Magnet Orientation: Affix the magnet piece to the moving door leaf directly aligned with the sensor body marker notch. Ensure the gap when the door is closed is 5–10 mm (well within the rated 15 mm maximum).
  • Mounting Medium: Use outdoor-rated 3M VHB double-sided acrylic foam tape (BOM Stage 5) for clean, vibration-proof attachment that resists door slams.
Pass — Stage 3b Door Sensor Gate

The DS-1 Door Contact Sensor is fully verified on the bench: reports open/close transitions across the Thread mesh within 50 ms, maintains <5μA deep sleep current, and operates 100% locally with zero cloud dependencies.
