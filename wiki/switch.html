Tinxy 4+1 Fan Smart Switch

The mains actuator. We do not assume a single central switchboard plate controls the entire apartment; instead, each room pattern has its own dedicated switch plate. To make the architecture completely uniform across all implementations, every plate controls a fan and lighting loads using the Tinxy 4 Node Smart WiFi Switch with Fan Regulators. Powered by an Espressif ESP8266 core, it provides native open-source local control with zero vendor cloud lock-in.

Component Identity — SW-1 (Uniform Module)

Tinxy 4 Node Smart Switch with Fan Regulators (Wi-Fi + RF Remote), SKU: Tinxy-4N-Fan from tinxy.in (Bengaluru, India). A compact retrofit module installed inside each room's standard Indian modular switchboard box behind existing switch plates. Driven by an Espressif ESP8266 microcontroller in a robust dual-MCU architecture: the ESP8266 handles 2.4 GHz Wi-Fi and Home Assistant communication, while a dedicated secondary MCU manages zero-crossing relay switching, stepped capacitor ceiling fan speed control (hum-free), and physical wall switch inputs (S1–S4, SF) with instantaneous offline response.

Why the ESP8266 + Dual-MCU Architecture Matters

Unlike monolithic Tuya chips or cloud-locked Beken microcontrollers, Tinxy uses a resilient two-tier hardware architecture:

  1. Espressif ESP8266 Core: Dedicated entirely to 2.4 GHz 802.11 b/g/n Wi-Fi networking and local communication. It accepts native custom open-source firmware like ESPHome or Tasmota, as well as direct local HTTP/MQTT API control. No cloud keys, no expiring developer tokens, and zero proprietary cloud dependencies.
  2. Secondary Relay/Fan Coprocessor: Communicates with the ESP8266 over an internal serial UART bus (9600 / 115200 baud). It handles inductive relay switching, mains zero-crossing detection, capacitor speed stepping for ceiling fans, and scans physical wall switch inputs (S1–S4, SF). Even if the ESP8266 is rebooting or Home Assistant is offline, the coprocessor continues operating the mechanical wall switches with sub-10ms response.
