The Design

Build the sensor; buy the mains actuator. This is the cost-controlled architecture for presence and daylight triggers on a fan and light, with Home Assistant running locally on the existing 2 GB SBC.

Final recommendation

Use one ESP32 + HLK-LD2410 + LDR in a low-voltage wall enclosure. Publish only presence, ambient-dark, and health state to Home Assistant through the local ESPHome API. Home Assistant can control the leading AZIOT 4 Node Plus candidate through tuya-local if the contacted Indian developer confirms the exact revision and it passes local/offline and electrical checks.

Do not add a second ESP32, DNS replacement, dedicated history database, or new HA computer. If the AZIOT revision fails confirmation or offline testing, stop rather than downgrade the safety boundary.

Installation boundary

The sensor box is low-voltage only and can use a nearby compliant USB adapter. The Tuya actuator stays in the existing switchboard or an appropriate certified enclosure and is installed by an electrician. Keep physical wall controls supported by the actuator. Never replace them with improvised low-voltage wiring unless the actuator manufacturer explicitly supports that installation.

Power-off test

Before any switchboard work, isolate the circuit, lock it out, and prove absence of voltage with an approved two-pole tester. Do not perform mains terminations yourself.

Project status

Current build target

Use one ESP32 + HLK-LD2410 + LDR sensor with ESPHome over local Wi-Fi. Home Assistant on the existing 2 GB SBC runs the rules and sends local on/off commands through tuya-local to the AZIOT faceplate switch. Fan-specific Tuya support is not required; the wall switch only needs supported local relay entities.
