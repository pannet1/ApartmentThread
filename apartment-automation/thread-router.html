Thread Router

The radio bridge. Battery sensors speak Thread; Home Assistant does not, so something has to join the two networks. It is one radio plus three pieces of software on the server — and it is the least understood part of the build.

Component identity — BR-1

ESP32-H2 dev board flashed with OpenThread RCP firmware, plugged into the Radxa, with the border-router service running on the server and one Thread dataset issued for the whole network. Change the radio, the firmware image or the border-router software and it becomes BR-2 — a fresh commissioning test and a fresh proof sequence. It fails independently of the server it sits on.

The board is not the router — this is the least understood part of the build

Plugging a radio into the server does not create a Thread router. Three separate things must exist: (1) RCP firmware on the radio so it becomes a dumb 802.15.4 transceiver, (2) border-router software on the server bridging Thread to the local network, (3) a Thread dataset — network key, PAN ID, credentials — issued once and shared to every node. None of the three has been selected or run. O-07

BR-1 — 802.15.4 Thread Radio
M5Stack ESP32-H2 Thread/Zigbee Gateway Module. Enclosed Espressif ESP32-H2-MINI-1 transceiver with Type-C USB and hardware encryption engine. Flashed with OpenThread Radio Co-Processor (RCP) firmware to turn the Radxa SBC into a local Matter/Thread Border Router. In stock on Robu.in.

Proof sequence — cheapest failure first

  1. Server up and reachable with the WAN cable out.
  2. Radio on RCP firmware; server detects it.
  3. Border-router service running; Thread network appears and survives a reboot.
  4. Commission a store-bought Thread device — any off-the-shelf sensor. This is the whole test: if a known-good device can't join and report, a custom sensor never will. closes O-07
  5. Remove and re-add it; confirm it works after a server reboot with the WAN out.
  6. Only then start the second presence sensor.

Full sequence with pass/fail gates: Install order, Stage 3. The host it runs on — RAM headroom, otbr-agent budget, Docker flags — is documented on the server page.

Why this comes before the sensors

A store-bought Thread device costs less than one PS-1 kit and tests exactly the same risk. Buying the router parts and a cheap test sensor together — before any presence sensor — moves the biggest unknown to the front of the queue. Both lines are on the buy list.
