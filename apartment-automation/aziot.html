Aziot 3+1 Fan Smart Switch

The mains actuator. We do not assume a single central switchboard plate controls the entire apartment; instead, each room pattern has its own dedicated switch plate. To make the architecture completely uniform across all implementations, every plate controls a fan and lighting loads using the Aziot 3+1 Fan Smart Switch.

Component Identity — SW-1 (Uniform Module)

Aziot 3+1 (Node) Fan Smart Switch (Wi-Fi + Bluetooth), model AZSS03F1. A compact retrofit module installed inside each room's standard Indian switchboard box behind existing switches. Controls 3 independent light/appliance channels plus 1 dedicated ceiling fan regulator channel (with hum-free multi-speed regulation). Retains physical manual toggle switch operation 100% offline.

Retrofit Switchboard Installation
Decentralized in-wall installation. One module sits inside each room's modular switchboard behind the faceplate. The external faceplate and physical mechanical switches remain unchanged, preserving manual operation for family members and guests.

Installation & Commissioning

  1. Isolate mains breaker before opening any switchboard.
  2. Electrician confirms neutral and fits one Aziot 3+1 module per switchboard behind the switches.
  3. Wire physical switch terminals to module switch inputs (S1–S3, S-Fan).
  4. Pair with Wi-Fi / Home Assistant locally (via Tuya Local integration).
  5. Verify each light and fan toggles from HA with WAN disconnected. closes O-10
  6. Confirm manual wall switches always override instantly, even if HA server is offline. closes O-18
